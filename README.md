# 📖 Project Overview

This project presents an end-to-end Business Intelligence solution for Maven Fuzzy Factory, a fictional e-commerce company. The solution integrates SQL Server and Microsoft Power BI to transform raw transactional and website data into meaningful insights through data profiling, exploratory data analysis (EDA), dimensional data modeling, DAX measure creation, and interactive dashboard development.

The final solution consists of five interactive dashboard pages:

- 📊 Executive Overview
- 💰 Sales Analysis
- 👥 Customer Analysis
- 🌐 Website Analysis
- 🔄 Refund Analysis

## 🛠️ Project Workflow

The project was completed through the following phases:

1. **Data Collection**
   - Imported raw e-commerce datasets into SQL Server.

2. **Data Profiling**
   - Validated primary keys, checked missing values, identified duplicates, and verified data quality.

3. **Exploratory Data Analysis (EDA)**
   - Performed SQL queries to analyze customer behavior, website traffic, product performance, sales trends, and refund patterns.

4. **Business Analysis**
   - Identified key KPIs and business metrics required for executive decision-making.

5. **Dimensional Data Modeling**
   - Designed a Star Schema to optimize reporting performance in Power BI.

6. **Dashboard Development**
   - Built relationships, created DAX measures, designed interactive dashboards, and implemented slicers, drill-through, and navigation.

## ✨ Key Features

- Performed comprehensive **Data Profiling** to identify missing values, duplicates, and data quality issues.
- Conducted **Exploratory Data Analysis (EDA)** to uncover customer behavior, sales trends, website performance, and refund patterns.
- Designed an optimized **Star Schema** data model for efficient reporting and analytics.
- Built interactive dashboards using **Microsoft Power BI** with intuitive navigation and drill-down capabilities.
- Created reusable **DAX Measures** for KPIs, growth analysis, customer metrics, and sales insights.
- Utilized **Power Query** for data transformation and preparation.
- Applied SQL for data extraction, validation, aggregation, and business analysis.
- Developed dashboards covering **Executive Overview, Sales, Customer, Website, and Refund Analysis**.

## 📈 Business Insights

- Identified monthly revenue trends and overall sales performance.
- Analyzed customer purchasing behavior and repeat customer trends.
- Evaluated website conversion performance across different traffic sources and devices.
- Measured refund rates to identify products and orders requiring attention.
- Tracked key KPIs including Revenue, Orders, Customers, Average Order Value, and Conversion Rate.
- Provided interactive filtering and drill-down capabilities to support business decision-making.
